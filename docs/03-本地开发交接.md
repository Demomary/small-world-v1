# 本地开发交接说明

## 1. Windows 环境

推荐：

- Windows 10 / 11
- Node.js 20 LTS 或更高
- npm

工程当前没有提交 `node_modules`，这是故意的；本地执行 `npm install` 安装依赖。

## 2. 最简单运行

解压工程后：

```text
1. 双击 一键安装.bat
2. 等安装 / build / test 结束
3. 双击 启动游戏.bat
```

也可以使用英文脚本：

```text
install.bat
start.bat
build.bat
test.bat
```

## 3. 命令行开发

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
```

测试：

```bash
npm test
```

预览构建结果：

```bash
npm run preview
```

## 4. 当前入口

程序入口：

```text
src/main.ts
    ↓
src/app/App.ts
```

App 当前承担较多装配与体验逻辑，因此后续开发优先进行模块拆分。

## 6. 当前核心世界链怎么走

### 种植

```text
点击种子

 ↓

 ↓

 ↓
点击花盆
 ↓
靠近花盆
 ↓
PLANT
 ↓
seed.lifecycle = consumed
pot.occupied = true

 ↓
plant.planted
```

### 浇水

```text
点击水壶
 ↓
PICK
 ↓
点击植物
 ↓
WATER
 ↓
植物 water + 0.35
水壶 water - 0.35
 ↓
plant.watered
```

### 离线成长

```text

 ↓
Date.now() - lastActiveTime

 ↓
growth / water / stage 更新
 ↓
plant.grew
```

## 7. 本地第一次开发建议

先不要继续往 `App.ts` 里塞逻辑。

第一步最好新建：

```text
src/action/ActionValidator.ts
src/action/ActionHandler.ts
src/action/handlers/PlantActionHandler.ts
src/action/handlers/ObjectActionHandler.ts
src/action/handlers/MovementActionHandler.ts
```

然后把 `WorldEngine.dispatch()` 逐步改成：

```text
Action
 ↓
Validator
 ↓
Handler
 ↓
State Change
 ↓
Event
```

第二步再建立：

```text
src/input/
src/interaction/
src/character/
src/world/SceneManager.ts
src/render/Camera.ts
```

这样后面添加触摸、语音、摄像头输入不会再改业务逻辑。

## 8. 如何验证一个新功能

不要只看页面有没有反应。

采用：

```text
Initial State
    ↓
Action
    ↓
Expected State Change
    ↓
Expected Event
    ↓
Persistence
    ↓
Reload
    ↓
Expected State
```

例如“浇水”：

```text
水壶 water = 1.0
植物 water = 0.4

WATER

水壶 water = 0.65
植物 water = 0.75

Event = plant.watered
```

然后重新加载，状态仍然存在。

## 9. 开发时的调试重点

建议后续增加 Event Trace 面板，至少能够看到：

```text
16:21:03 Action PICK seed
16:21:03 State seed.location=carried
16:21:03 Event object.picked
16:21:07 Action PLANT seed -> pot
16:21:07 State pot.occupied=true
16:21:07 State seed.lifecycle=consumed
16:21:07 Event plant.planted
```

这会比单纯看日志容易很多。

## 10. 当前设计中最容易被破坏的边界

不要做这些：

```text
UI → WorldState
UI → IndexedDB
AI → WorldState
AI → PixiJS
Knowledge → PixiJS
Game → IndexedDB
Renderer → 修改世界状态
Animation → 修改业务状态
```

正确方向始终是：

```text
UI/Input/AI/NPC
      ↓
     Action
      ↓
   Validator
      ↓
    Handler
      ↓
  WorldState
      ↓
   WorldEvent
      ↓
Feedback / Knowledge / Recommendation / Persistence
```

## 11. 内容扩展方法

当前很多内容还硬编码在 `App.createWorld()`。

后续应迁移到：

```text
data/world/
data/knowledge/
data/games/
data/experiments/
data/characters/
data/assets/
```

目标是：

```text
增加一只兔子
```

不应该需要修改运行时逻辑，只需要增加数据。
