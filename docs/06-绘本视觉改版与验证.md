# 绘本视觉改版与验证

日期：2026-09-17。用户确认以绘本风 2.5D 探索游戏重新制作原型的场景、美术和交互界面。

## 已完成

- 小院、公园、森林改为完整插画场景，包含房屋、温室、花圃、游乐设施、池塘、小溪和木桥。
- 角色、动物、种子、水壶、背包、故事书等均使用项目内原创 SVG 游戏资产，加载时栅格化为 PixiJS 纹理。无外部图片服务依赖。
- 渲染器复用场景与对象，不再逐帧销毁重建所有图形；按对象位置进行深度排序。
- 新增统一世界坐标、镜头跟随、边界限制、手机横向拖动，以及窄屏和横屏适配。
- 大型操作面板替换为场景导航、简洁目标提示、底部工具栏和短暂对话。图标使用 Lucide。
- 新增发现册；听声游戏、问答和融冰实验统一样式，小游戏支持 Escape 关闭并清理计时器。
- 拿取、播种、浇水和生长有图形反馈；第一次成功浇水将生长值推进到 0.15，立即显示嫩芽。之后浇水只补水，不继续跳过生长阶段，后续生长仍由原有时间模拟负责。
- 增加 REFILL 动作：拿着水壶接近当前场景的池塘或小溪可补满水。切换场景保留手持物品。
- 旧存档只迁移仍在原始位置的静态道具，保留已移动、携带和消耗的物品状态。迁移通过标记保证只运行一次。

## 主要文件

| 文件 | 用途 |
|---|---|
| `src/render/SceneArt.ts` | 三个场景的静态插画 |
| `src/render/ObjectArt.ts` | 角色、道具、动物和植物阶段插画 |
| `src/render/Renderer.ts` | 缓存纹理、对象投影、点击区域、视觉反馈 |
| `src/render/Camera.ts` | 镜头和坐标转换 |
| `src/ui/game.css` | 游戏界面及桌面、手机布局 |
| `src/ui/Icons.ts` | Lucide 图标 |
| `src/world/GardenProgress.ts` | 种植引导与一次性布局迁移 |
| `src/world/WorldEngine.ts` | 首次浇水反馈及 REFILL 动作 |

## 验证结果

- `npm run build`：通过 TypeScript 检查及 Vite 生产构建。
- `npm test`：4 个文件，9 项测试通过，覆盖原有种植、首次浇水、补水条件、镜头与迁移。
- Playwright + 本机 Edge：1440×900、390×844、320×568、844×390 实机截图检查；被检查的工具按钮均在视口内。
- 桌面实际 Canvas 点击完成拿种子、种植、拿水壶、浇水；手机触控目标提示完成同一流程。
- 实测跨场景携带水壶、点击水面中央补水、发现册、问答、听声游戏、融冰实验、关闭弹窗、声音开关、家长面板与刷新后的存档恢复。
- 画布像素检查：抽样得到 7475 种颜色，相邻两帧有 38801 个变化像素；确认非空且存在动画。
- 浏览器验证过程中没有捕获到页面脚本异常。截图位于 `artifacts/visual/`。

## 本地运行

本次服务运行于 `http://127.0.0.1:5174/`，因为 5173 已被其他进程占用。服务在后台运行；如果电脑重启，可进入项目执行 `npm run dev -- --host 127.0.0.1`，以终端实际打印的地址为准。
